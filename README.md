# 🛒 Catálogo Interativo Mobile com Listagem de Produtos por Categoria

Um aplicativo mobile responsivo e leve desenvolvido em **React Native** utilizando o **Expo**, criado para apresentar produtos de uma loja online[cite: 2].

## 💡 Sobre o Desafio
O projeto consiste na primeira versão de um catálogo interativo, com foco na listagem de produtos por categoria (masculina e feminina), navegação fluida entre telas e o consumo de uma API REST real via Axios[cite: 2].

## ✨ Principais Funcionalidades
* **Tela de Login:** Simulação de acesso com validação de campos e armazenamento temporário de dados[cite: 2].
* **Tela de Lista de Produtos com Abas:** Organização dinâmica por categorias (masculino/feminino) consumindo dados da API[cite: 2].
* **Tela de Detalhes do Produto:** Exibição completa contendo nome, imagem, descrição, preço e desconto[cite: 2].
* **Logout:** Botão funcional para sair e retornar à tela de login, limpando os dados armazenados[cite: 2].

## 🛠️ Tecnologias Utilizadas
* React Native (com Expo)[cite: 2]
* Axios[cite: 2]
* React Navigation
* Redux Toolkit (opcional)[cite: 2]
